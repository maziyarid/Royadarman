## This branch (`presentation-rescue-2026-09-16`)

Ships so far:

1. Gap table + hourly progress log.
2. `backend/package-lock.json` and frontend CI `npm ci && npm run build` on `backend/`.
3. CMS media sanitizer (reject SVG/GIF, sniff bytes, header-size gate before GD, EXIF orientation, re-encode, ULID filename, application serve URL).
4. Service-first Blade homepage (`چه خدمتی نیاز دارید؟`) with neighbourhood search that actually ranks `/services?q=`.
5. Permanent `/pres` presentation portal with 30-minute signed role handoffs when demo access is on.
6. Guided patient-request wizard with Arabic parity; walkthrough remains when intake is closed.
7. Session inventory/revoke on the configured session store with same-connection transactional audit (split-store: revoke-first, best-effort audit).
8. Staff provision auto-revokes sessions on role change, MFA secret replacement, and inactive→active reactivation (RPH-5 AC3), with revoke-first identity+session transactionality.
9. Production preflight refuses split `SESSION_CONNECTION` using `SessionInventoryService` resolvers (shared audit connection required; no fake XA).

PHPUnit evidence, referral SLA events, Haversine discovery, and `infra/` remain next. Canonical Blade stays Laravel; the App Builder preview is staging-only.

## Non-negotiable leftovers (do not regress)

- Laravel 13 / PHP 8.3 / MariaDB / Blade+Vite+Tailwind
- OTP + staff MFA
- Fail-closed `ClinicalDocumentPolicy`
- OPG quarantine → ClamAV
- Owner has no clinical-document access
- No autonomous OPG diagnosis
- No payments / marketplace claims
- No production force-push; staging only for review
