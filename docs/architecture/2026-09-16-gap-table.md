## This branch (`presentation-rescue-2026-09-16`)

Ships immediately:

1. This gap table.
2. `backend/package-lock.json` and frontend CI `npm ci && npm run build` on `backend/`.
3. CMS media sanitizer (reject SVG/GIF, sniff bytes, GD re-encode, random ULID filename) with spoofed-extension, GIF, malformed, and polyglot tests.

Presentation UX (homepage, guided journey, `/pres/`, six role workspaces) is staged as a Persian-first preview for review. Canonical Blade implementation follows on this branch in subsequent commits so production stays Laravel.

## Non-negotiable leftovers (do not regress)

- Laravel 13 / PHP 8.3 / MariaDB / Blade+Vite+Tailwind
- OTP + staff MFA
- Fail-closed `ClinicalDocumentPolicy`
- OPG quarantine → ClamAV
- Owner has no clinical-document access
- No autonomous OPG diagnosis
- No payments / marketplace claims
- No production force-push; staging only for review
